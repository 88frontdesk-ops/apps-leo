# Weather-B

Weather-B displays current conditions, hourly and daily forecasts, UV information, astronomical times, and weather alerts.

## Data providers

- **Open-Meteo** — current weather, hourly forecast, daily forecast, UV, precipitation, wind, visibility, and related weather data.
- **National Weather Service (NWS)** — active weather alerts for U.S. locations.
- **Browser Geolocation** — used only when Weather-B needs an initial current location and the user grants location permission. No IP-geolocation service is used.

Weather-B does not use an analytics or telemetry service for these weather requests.
